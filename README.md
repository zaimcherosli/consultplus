# ConsultPlus Financial Advisory

Laman web rasmi **ConsultPlus Financial Advisory** - Pakar konsultan pinjaman peribadi bank dan pinjaman koperasi di Malaysia.

## 🚀 Ciri-Ciri Utama
- **Halaman Utama & Maklumat Servis**: Panduan lengkap pinjaman bank, koperasi & penyatuan hutang (overlap).
- **Semakan Kelayakan Pantas**: Kalkulator dan borang semakan pantas untuk penjawat awam dan swasta.
- **Kadar & Pakej Telus**: Maklumat kadar keuntungan serendah 2.95% & kelulusan 24-48 jam.
- **Responsif & Pantas**: Dibina dengan Tailwind CSS & JavaScript tulen.

## 📁 Struktur Fail
- `index.html` - Halaman Utama & Panduan Ringkas
- `about.html` - Maklumat Profil & Kelebihan ConsultPlus
- `pinjaman-bank.html` - Pakej Pembiayaan Peribadi Bank
- `pinjaman-koperasi.html` - Pakej Pinjaman Koperasi Penjawat Awam
- `penyatuan-hutang.html` - Pelan Overlap & Settle Luar
- `contact.html` - Hubungi Konsultan
- `verify.html` - Pengesahan Status & Semakan
- `assets/` - CSS kustom, JavaScript interaktif, dan imej
